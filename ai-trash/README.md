# AI кошче (`ai-trash/`)

Единна папка за **всичко временно и „боклук“**, което иначе замърсява корена на проекта: чернови на документи, изрязани фрагменти от файлове, бележки от чат, `_tmp-*` скриптове, дублирани експорти, логове от експерименти.

## Правила

1. **Слагай тук**, не в `Desktop/`, не в корена на репото и не в `src/` без причина.
2. Съдържанието (освен този `README.md`) е **`.gitignore`-нато** — няма да влезе в git по подразбиране.
3. Периодично **изтривай** съдържанието, когато вече не ти трябва (локално почистване).

## Примери за какво да отива тук

- `snippet-*.txt`, `draft-*.md`, `paste-*.html`
- Частични екстракти от големи файлове преди merge
- Еднократни debug скриптове и изходи
- Копия на конфиг „за проба“

## English

Single **AI / scratch wastebasket**. Put drafts, cut fragments, temp scripts, and one-off exports here instead of polluting the repo root. Contents are gitignored (this file stays tracked). Delete locally when done.
