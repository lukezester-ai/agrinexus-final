# Skill Squad website

Standalone bilingual (English/Bulgarian) company website for Skill Squad. It is intentionally separate from the AgriNexus application and uses plain HTML, CSS and JavaScript without a build step or runtime service.

## Preview

Open `index.html` in a browser. The language toggle switches between English and Bulgarian and remembers the visitor's choice.

## Configuration

Edit `site.config.js` to change the public contact email or AgriNexus product URL. Contact currently points to `lukezester@gmail.com`.

## Deploy

The site can be served as static files from the repository root. No build command or framework root directory is required. Configure the hosting project to use the repository root as its output source.

## Content notes

AgriNexus is described as in development. The page avoids invented client names, results, and unsupported technology/vendor claims.
